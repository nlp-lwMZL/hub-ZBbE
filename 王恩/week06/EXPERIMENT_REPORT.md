# Week06 分类方法对比：实际实验报告

本次选择“更换数据集”：TNEWS 新闻分类 → 项目 week03/v12 的 12 语种识别。五种基础方法实际完成训练与测试；多语种预训练模型的两种路径完成离线流程测试，但未下载正式预训练权重、未报告其分类效果。

## 实验设置

- 标签：`ar/en/es/hi/ja/ko/pt/ru/th/tr/vi/zh`；seed=42。
- 完整训练集 9,600 条（800/类）；小样本训练集 1,200 条（100/类）。
- 两组实验使用相同 Dev 1,200 条、Test 1,800 条；已检查归一化去重，三组之间无完全重复文本。
- CNN 训练 5 epoch，仅按 Dev Macro-F1 选权重；TF-IDF 超参数预先固定。未用 Test 选择超参数。
- 运行环境：Python 3.12.13，macOS arm64，CPU（PyTorch 两线程，传统方法依赖库默认线程）；numpy 2.5.5，scikit-learn 1.5.2，PyTorch 2.15.0。
- 耗时为一次运行测量，包含训练及 Dev 选模，不包含模型初始化或权重加载，不能视为稳定性能基准。

## 完整数据结果

| 方法 | Test Accuracy | Test Macro-F1 | 训练/选择秒 | 测试推理秒 |
| --- | --- | --- | --- | --- |
| rule | 0.8694 | 0.8743 | 0.002 | 0.019 |
| tfidf_nb | 0.9967 | 0.9967 | 0.434 | 0.055 |
| tfidf_lr | 0.9928 | 0.9928 | 6.036 | 0.074 |
| tfidf_svm | 0.9944 | 0.9945 | 1.115 | 0.053 |
| char_cnn | 0.9867 | 0.9868 | 81.144 | 1.955 |

CNN 最佳权重来自第 4 轮，Dev Macro-F1=0.9917；其后训练轮次没有被当作最终模型。

## 训练数据量对比

| 方法 | 800/类 Macro-F1 | 100/类 Macro-F1 |
| --- | --- | --- |
| rule | 0.8743 | 0.8467 |
| tfidf_nb | 0.9967 | 0.9834 |
| tfidf_lr | 0.9928 | 0.9812 |
| tfidf_svm | 0.9945 | 0.9774 |
| char_cnn | 0.9868 | 0.9346 |

注意：规则方法在多数类并列时使用训练样本中最先出现的标签回退。缩小训练集会改变打乱后的首个标签，因此规则分数变化来自回退类别变化，不应解释为规则从更多数据中学到了知识。

## 结果分析

1. 此固定语种测试集上，TF-IDF + NB 的 Macro-F1 最高，为 0.9967，训练约半秒；小样本仍达到 0.9834。字符 n-gram 能直接利用文字系统、拼写和常用短片段。
2. 规则 Macro-F1 为 0.8743。它能区分明显不同的文字系统，但大量拉丁字母文本会混到回退类别：tr→pt 102 条、es→pt 61 条、vi→pt 45 条。规则覆盖知识与回退策略限制了效果。
3. 字符 CNN 的 Macro-F1 为 0.9868；缩小训练集后降至 0.9346。在当前训练轮数和网络规模下，增加模型复杂度没有超过字符 TF-IDF 基线，且训练成本明显更高。这里只能比较当前配置，不能断言 CNN 在所有语种识别任务都更弱。
4. 主要剩余混淆是西班牙语/葡萄牙语：NB 在 es→pt 和 pt→es 各错 2 条；CNN 在 es→pt 错 13 条。应优先检查这些共享词形的语种，而非只优化已接近满分的文字系统类别。
5. 当前结果支持“先建立便宜且可复现的传统基线，再评估是否值得增加预训练模型成本”。尚未运行正式预训练模型，不能据此给出其胜负。

## 验证与复现

- 四项基础检查通过：归一化去重与固定抽样、冲突标签拒绝、缺失预测类别仍计入 Macro-F1、CNN 补齐位置不影响输出。
- 可选 Encoder 检查通过：本地随机初始化的极小 BERT，分别走冻结/微调的两轮训练、Dev 选模、Test 推理及保存；验证冻结参数不变、微调参数变化。随机模型只用于程序正确性检查。
- `outputs/results.json` 和 `outputs/n100-s42/results.json` 提供所有逐类指标；同级 `*_predictions.json` 可核对每条错误。两组 manifest 的 Test 样本 ID 一致。
- scikit-learn 1.5.2 与本机较新 SciPy 的组合出现 `Unknown solver options: iprint` 优化器提示，LR 正常完成拟合，未出现收敛失败。

复现完整实验：

```bash
python run_experiments.py
python run_experiments.py --train-per-class 100 --output-dir outputs/n100-s42
```

## 局限

仅运行一个随机种子，差异没有置信区间；数据为项目提供的学习数据，本次未重新验证原始采集来源、近重复或模板相似性。去除完全重复不等于排除了所有分布偏差。高分不能直接推广到真实业务或新闻分类。
