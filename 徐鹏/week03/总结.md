1. **Adam 优化器**：结合动量与自适应学习率，解决 SGD 学习率难调、收敛慢问题，常用参数 lr=1e‑3、betas=(0.9,0.999)。
2. **Embedding 层**：把离散字符 / 单词转为稠密向量；设置`<PAD>`补全不等长句子、`<UNK>`处理未登录字符，字符级适合多语种任务。
3. **CNN（1D 卷积）**：靠局部感受野、权重共享提取文本 n‑gram 局部特征，核心参数：卷积核大小、步长、padding。
4. **RNN/LSTM**：用于序列建模。普通 RNN 存在梯度消失；LSTM 依靠遗忘 / 输入 / 输出门 + 细胞状态，保存长距离信息；双向 LSTM 同时读取正反序列。
5. **池化层**：压缩序列特征。NLP 常用全局最大池化，把不定长序列变成固定长度向量，抓取关键特征。
6. **归一化**：解决内部协变量偏移，加速训练。BatchNorm 依赖 batch 大小；**LayerNorm 更适合 NLP 变长序列**。
7. **Dropout**：训练时随机屏蔽神经元，防止过拟合；训练和推理模式行为不一样，预测务必开启 eval ()。
