### 自动生成的关键对比（只统计两边都跑了的组合）

- 预训练编码器（BiLSTM → BERT+CRF）：论元F1 0.5647 → 0.5672（+0.0025，相对 +0.4%）
- 解码器（Linear → CRF）：论元F1 0.5598 → 0.5672（+0.0074，相对 +1.3%）
- 联合抽取 → 两段式流水线：论元F1 0.5672 → 0.3527（-0.2145，相对 -37.8%）
- CRF 解码加 BIO 硬约束（同一 checkpoint）：论元F1 0.5672 → 0.6418（+0.0746，相对 +13.2%）
- LLM 零样本 → 少样本（DeepSeek API）：论元F1 0.5224 → 0.5395（+0.0171，相对 +3.3%）
- 零样本换模型（Qwen3-0.6B → Qwen2-0.5B，n=60）：论元F1 0.1167 → 0.0000（-0.1167，相对 -100.0%）
- 零样本换模型（Qwen2-0.5B base → Qwen2.5-0.5B-Instruct，n=60）：论元F1 0.0000 → 0.0000（+0.0000，相对 +0.0%）
- LoRA 换模型（Qwen3-0.6B → Qwen2-0.5B）：论元F1 0.6971 → 0.6234（-0.0737，相对 -10.6%）
- 判别式 BERT+CRF → 生成式 Qwen2+LoRA：论元F1 0.5672 → 0.6234（+0.0562，相对 +9.9%）
- 判别式 BERT+CRF → 生成式 Qwen3+LoRA：论元F1 0.5672 → 0.6971（+0.1299，相对 +22.9%）
- n=200 论元 F1 最高：**Qwen3-0.6B + LoRA（课程原始） / L4 LoRA SFT**（0.6971）
- 延迟最低：**无模型 / L0 规则（词典+正则）**（2.164 ms/句）
