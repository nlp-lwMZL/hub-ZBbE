## 三、从表里能直接读出的结论

- **BERT 最大收益**：CLS 池化 + 数据量 50k，Δ Macro-F1 +0.1538，低类 F1 0.3990（基线 0.0075）。
- **BERT 最差臂**：CLS 池化 + 截断长度 128，Δ -0.0050；最好臂：CLS 池化 + 数据量 50k。
- **救低类最有效**：CLS 池化 + 数据量 50k，低类 F1 0.0075 → 0.3990（Δ +0.3915），低类 R 0.2884。
- **尾部塌缩（只预测 2 类）**：CLS 池化 + 拼接标题、CLS 池化 + FGM 对抗（eps=1）、Max 池化、CLS 池化 + 截断长度 128。这些组的 accuracy 看起来不低，但低类 F1=0，不能选。
- **LLM 侧超过锚点的臂**：Qwen3-0.6B LoRA 微调 10k（标题+描述）。其余差距落在噪声内或未训练，别解读成方法优劣。
- **口径提醒**：以下臂与各自锚点输入字段不同，差距里混着「标题」这个变量，不能全归因于方法：CLS 池化 + 拼接标题、Qwen3-0.6B 5k 仅描述。

## 五、落地建议

1. **先看低类，再看 Macro-F1。** 本任务低类占 8.9%，任何「accuracy 不错但低类 F1=0」的配置都不能上线；类别权重 sqrt / Focal / 扩到 20k–50k 是表里有数据的解法。
2. **一次只改一个变量。** 同一族内同输入、同数据量的两行才能解释因果；「拼标题」组同时改了输入，不能和 desc 组直接归因。
3. **Δ<0.024 视为噪声。** 3k 样本下这点差距可能是抽样波动；要定论需要配对 bootstrap 或在另一个 seed 上复现。
4. **ECE 只用于同族诊断。** 想拿置信度做低置信转人工，BERT 族内比较即可；LLM 的 conf 分母不同，先看风险覆盖曲线（AURC）再做决定。
5. **跨族只做「够不够用」的判断。** 表里最佳 LLM 与最佳 BERT 的差是不同模型族、不同输入口径下的绝对差，只回答「值不值这个推理成本」，不回答「哪个方法本质上更好」。
